# Product Overview

## Promise

Turn your CV + GitHub into a professional identity recruiters can understand and verify.

## Target Initial Users

- Early-career software engineers building a public profile
- Experienced developers who want recruiters to see verified evidence, not just claims

## MVP Boundary (Stages 1-3)

1. Account creation and authentication
2. Resume upload and AI-powered profile extraction
3. Manual review and editing of profile data
4. Public profile publishing to username.yourdomain.com

## Explicit Non-Goals (Stage 0)

- Resume PDF generation
- Recruiter AI chat
- GitHub OAuth and repository import
- Payment processing
- Custom domain support
- Job matching
- Analytics dashboards
- Admin interfaces
